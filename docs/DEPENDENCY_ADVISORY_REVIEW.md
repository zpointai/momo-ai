## Applied remediation and residual risk

Vite 6.4.2 -> 6.4.4; Babel core 7.29.0 -> 7.29.7 and its compatible helper family; baseline-browser-mapping 2.10.20 -> 2.11.27; browserslist 4.28.2 -> 4.29.3 and browser metadata; http-cache-semantics 4.2.0 -> 4.3.0; nanoid 3.3.11 -> 3.3.20; postcss 8.5.10 -> 8.5.29; source-map-js 1.2.1 -> 1.2.2. All 27 changed package resolutions are development tooling, remain within existing upstream ranges and keep the same major version. No runtime inventory entries changed.

The post-update lockfile audit reports 8 moderate affected-package entries, all from GHSA-hp3w-g68c-fv3c (sprintf-js); zero high, low or critical. This is one residual underlying advisory, not eight independent vulnerabilities. No supported patched sprintf-js or newer electron-builder exists at review time. Do not force a downgrade or replace the packaging toolchain for this preview.

Temporary acceptance recommendation: the library is excluded from the packaged application and Relay. The vulnerable formatter can run only when optional proxy/download logging is enabled and a controlled format string reaches it. The global-agent callers use fixed format messages and dynamic data in context; ordinary CI does not expose this as a network service and ROARR_LOG is unset. Dependencies are installed in CI, but installation alone is not exploitability. Reassess on an upstream fix, next release, or before accepting untrusted logging/build inputs.

Open Dependabot PRs #1-#8 remain unmerged: Actions majors (#1/#2), Twilio major (#3), Vite major (#4), typescript-eslint minor (#5), React/types minor (#6), plugin-react major (#7), Tailwind minor (#8). The Vite security need is covered here, but #4 still proposes a separate major upgrade, so it is not closed as fully superseded. No proposed target version is incorporated; no PR is blindly merged or closed.
