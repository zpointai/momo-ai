## FFmpeg disposition

Electron's release configuration uses `ffmpeg_branding="Chrome"`, `proprietary_codecs=true`, and a shared FFmpeg component. The exact Windows x64 generated configuration has GPL, nonfree and version-3 options disabled; no x264 or other GPL external library is enabled. Codec support is not itself a GPL license switch. The FFmpeg DLL is unchanged, dynamically imported by the main PE, and not subject to a MoMo replacement lock. LGPL library source accompanies every ZIP, including upstream Chromium changes and Electron's macOS-only patch. This satisfies the chosen source-plus-shared-library distribution route; no promise-only source offer is used. Patent rights are separate from this copyright/notice review.

The huge canonical Chromium notice file includes build/test tools and alternative-license text. For example, the DXC entry explicitly separates GPL Autoconf build/test code from the LLVM runtime grant. A GPL/AGPL/non-commercial word anywhere in that file is not evidence that the running Windows application contains a component under that restriction. The complete canonical notice is preserved rather than shortened based on keyword filtering.

## Microsoft disposition

Physical inventory identifies three Microsoft-origin graphics DLLs. DXC and the post-1.8.2502 DXIL validator use their upstream open-source grants. The unchanged d3dcompiler_47.dll uses Windows SDK distributable-code terms, retained in licenses/microsoft and described in [RUNTIME_NOTICES.md](../RUNTIME_NOTICES.md). This is separate from building the project helpers.

The earlier helper binaries used proprietary MSVC runtime objects whose redistribution entitlement could not be established from standalone Build Tools. Those binaries and build recipes have been replaced. The supported build now uses only the verified portable LLVM-MinGW toolchain, with its own Win32 headers/import libraries and permissively licensed runtime objects. It links the Windows-provided UCRT dynamically. No installed Visual Studio product or SDK is consulted, installed or distributed by the helper build.

The complete MinGW aggregate notice includes historical text about optional math implementations and Wine headers. Actual linked-object/source review found no Cephes or GPL implementation in these two helpers. The two used LGPL-marked headers supply Windows API declarations; no Wine implementation library is linked. Their exact source and license are included, along with the complete MIT helper sources and standalone build scripts. Toolchain build utilities are not runtime components and are not distributed in the app. See [native provenance and rebuilding](NATIVE_BUILD.md).

Raw download, link-map and compiler evidence stays outside tracked content. Public runtime notices and required source accompany the Windows ZIP. See [release gate](../PUBLIC_RELEASE_GATE.md) for validation status.
