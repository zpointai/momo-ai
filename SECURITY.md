# Security policy

Community Preview 0.1 is the initial supported preview target. There are no security support or response-time guarantees.

The preferred reporting route is GitHub's **Report a vulnerability** feature in the official repository's Security tab once private vulnerability reporting is enabled. Until that route exists, do not put vulnerability details or private material into a public issue. Use an already established private contact with the maintainer, or wait for the private reporting route.

Never attach API keys, OAuth files, private logs, email content, account IDs, database files, phone numbers or device/network identifiers. Describe affected versions, reproduction steps using synthetic data, and expected versus observed authority behavior. Share sensitive evidence only through the confirmed private route.

See [security model](docs/SECURITY_MODEL.md). GitHub secret scanning, push protection, dependency alerts and private vulnerability reporting remain publication-time settings; this file does not claim they are enabled.
